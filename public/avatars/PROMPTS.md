# Avatar generation

Created with the built-in Image Generation tool. Original generated PNGs are copied into this project and served as `/avatars/player.png` and `/avatars/opponent.png`.

## Player — final prompt

Use case: stylized-concept. Asset type: finished anime game character portrait for the upper half of a left-side versus panel. Input images are CHARACTER REFERENCES only, not edit targets. Create a new dynamic polished anime illustration of the same recognizable cat-eared female character: green-gold eyes, black hair with prominent blonde forelock and long cream/blonde strands, white hair bow, black cat ears with white tufts, black/cream/gold oversized jacket, star belt and dark pleated skirt, calico tail. Depict an adult young woman, confident playful battle-ready pose, hands raised near chest, three-quarter view facing slightly right. Framed head to upper thighs, centered face in upper third, ear tips fully within frame, expressive clean anime eyes and crisp detailed linework with painterly cel shading. Background intense orange and gold flame-shaped energy, warm embers, dark crimson perimeter, dramatic light behind silhouette. Slight steampunk brass details consistent with reference outfit. Portrait aspect 4:5. Full bleed artwork, no text, no letters, no logos, no UI, no border, single character. Keep character big and readable when displayed at 320px wide by 400px tall. Do not produce a character sheet.

References: the user-supplied `Ua.jpg` character sheet and `img_6225_84ccb9db33b3f436519bd5883c4f0859.png` character illustration.
